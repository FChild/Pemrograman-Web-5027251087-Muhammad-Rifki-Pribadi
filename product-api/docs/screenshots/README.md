# Screenshot evidence

Simpan screenshot asli halaman aplikasi, Postman, dan Prisma Studio pada folder ini.

- Paket belum memuat screenshot browser karena Chromium diblokir pada lingkungan pembuatan. Folder ini tidak boleh dianggap bukti visual yang sudah selesai.
- Hasil API dan komponen yang benar-benar berhasil diuji tersimpan di `../evidence/`.
